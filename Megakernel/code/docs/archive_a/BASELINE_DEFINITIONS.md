# 基线与归因

B0 使用 torch eager 多算子，显式创建中间张量。B1 是同一 Stage A megakernel 后端的 none 计划；W1–W5/W7 为一个内核，W6/W8 除有状态调度器的状态复位外为一个任务执行内核。B2 只改写指定的一条规则。对于 W6/W8，B1 与 B2 除任务顺序约束外使用完全相同的任务数学、worker 数和发布协议。固定顺序强基准与按拓扑层次的 S5 对照分别注明；链图没有可移除约束时为 NO_OP。

成本比较以同一 Case 的 B1/B2 为增量，B0/B2 为总体加速，B1−B2 为绝对节省微秒。保留所有退化。独立实现的 torch SDPA 控制、官方源码的前向算子以及可选 Liger 使用各自名称，单独预检和计时。官方普通 GEMM 的低精度输出边界可能和 B1 的 FP32 epilogue 不同，超限时只记录该控制的失败。SDPA 与官方 FlashAttention 的在线归约属于强基线自身。额外强基线的 autotune 和初始化在正式图捕获之前完成。

同一 GPU 的进程锁串行化 Stage A 作业。请预留独占测试窗口，环境锁无法阻止其他用户的无关 GPU 进程。
