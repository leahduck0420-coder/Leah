# 数值与合法性

以 FP32 累加，按各算子输出契约进行 FP16/BF16 舍入。W7 保留 Qwen RMS 归一化后的转换、两个线性输出和 SwiGLU 的低精度边界。W8 Q/K/V 带 bias，RoPE 使用半维旋转和 theta=1000000，GQA 各七个 Q 头共享一 KV 头，decode 的因果掩码含历史位置偏移。B0、B1、B2 使用同一次输入和相同权重，输出与独立数学参考对比。W6 另外以 CPU 按拓扑顺序累加，逐任务检查最终状态和恰好一次执行。普通和极值输入均运行两次检查 bitwise 重复一致性；W1 增加物理 stride=2。其他 GPU 模板使用明确的连续 ABI。tail 形状是独立参数层，不把布局拒绝算成有效性能。

逐元素判据为 abs(actual−ref) ≤ atol+rtol·abs(ref)。W1–W8 的 BF16 (rtol,atol) 分别是 (.009,.0006)、(.009,.002)、(.016,.002)、(.014,.0003)、(.016,.0004)、(.009,.0005)、(.020,.0003)、(.020,.0006)。FP16 的两项分别乘 .28、.35。所有非有限值导致检验失败。max_rel 用 1e−12 保护分母，同时报告 max_abs、RMS、NaN/Inf 和超限数。该首轮契约在代码中固定；正式数据发现超限后应检查错误，不应原地放宽原运行契约。

负例覆盖跨 program、过期值、重叠/缺失归约贡献、统计量不完整、错序分片、循环前驱。折叠和浮点容差的比较记录实际误差。INVALID_REJECTED 表示规则合法性如预期拒绝。NO_OP、UNSUPPORTED、BLOCKED、COMPILE_ERROR、RUNTIME_ERROR、OOM、TIMEOUT 均不产生可用性能标签。
