# Program 所有权与单策略实验的数学契约

把逻辑 program ID 的各轴及元素坐标各轴按二进制展开。每个 tensor 有独立的 program 列矩阵 A 和局部基 B。其投影为 O(p,u)=Ap ⊕ Bu，所有线性运算在 GF(2) 上进行。真实张量保留按轴的边界掩码 D(p,u)。元素 t 的活跃所有者为 {p | 存在 u，D(p,u) 且 O(p,u)=t}。填充域的核维数与输出唯一写入分别记录。每个候选以版本化的生产者、消费者和边作为其作用域；每种测量只允许一项 S 变换。

1. **S1 局部交接。** 对固定 p，把消费端的需求写成 t=Aᵣp ⊕ Bᵣv ⊕ δ。求局部解 B𝓌u=(Aᵣ⊕A𝓌)p ⊕ Bᵣv ⊕ δ。每一列的消元残差均为零，并通过边界、活期和可见性检查时，替换物化的交接边。W1 的 δ 是已知局部 XOR 排列，对非零位还按 PTX 指令验证具体交接层级。
2. **S2 分块迁移。** 选择合并因子 f=2ᵇ，把旧 program 分块索引写成 p=fq+j，0≤j<f。新所有权把 q 放在 program 侧、j 放在局部侧。原有效集合是各 (q,j) 活跃子块的不相交并；普通输出保留唯一写者。对于归约，保存贡献标识和多重集。Stage A 对输出行或列重分块；split-K 贡献的保持另有 CPU 对照。
3. **S3 充分统计量。** 当 hᵢ=R(xᵢ,σ) 且 σ=⊕ⱼs(xⱼ) 已归约完成时，交接 σ 的数据边，同时延长 x 的活期至最后一次重建。RMSNorm 使用逆均方根，LayerNorm 使用均值及逆标准差，Softmax 使用行最大值和移位后的指数和。舍入点属于计算契约。特征单独计入统计量字节、重建次数和原输入重读。
4. **S4 归约切片。** 将有效域 I 划分为按指定次序消费的半开区间 I₀,…,Iₕ₋₁。各片互不重叠且并集为 I。累加状态 aⱼ₊₁=F(aⱼ,h[Iⱼ],x[Iⱼ])。浮点累加保持基础累加单元及其顺序，程序在最后一次读完成后才可复用位置。每个候选输出实际区间和尾片；单片控制归入 NO_OP。
5. **S5 就绪调度。** 给定任务数据边 E 和执行边 E′，E 的每条依赖须受 E′ 的先行关系保护。任务 t 在所有前驱完成并发布后可被唯一 worker 认领。执行阶段采用 GPU 范围的 release/acquire 发布；有界扫描支持 worker 退出。使用固定/分层拓扑作为 B1，对比放宽至真实数据就绪关系的 B2。任务插桩独立于计时，记录每个任务的 worker、完成次数、起止时间并核对每条边。

单规则实验通过比较同一编译模板的 B1 和 B2 来度量边际收益。若 ΔT=median(T_B1)−median(T_B2)，则正值表示本配置的实测节省。保留回退样本和配对批次置信区间，留给后续建模。当前阶段的合法性判定独立于 GPU 时间；任何性能结论均须有目标环境的测量记录。
