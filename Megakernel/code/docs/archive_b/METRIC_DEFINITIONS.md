# 测量口径

延迟为每次调用的微秒，包含必要任务状态 reset。预热、JIT、独立正确性检查和插桩轨迹均单列。B1/B3 为增量加速，B0/B3 为总加速，B1−B3 为节省微秒，同轮最快 B2/B3 衡量超越单策略的幅度。输出均值、标准差、P10/P90、中位数、bootstrap 95% 区间。paired_speedup_ci95 针对按批配对的比值，中位延迟比单独报告。排序按中位时间，不能将接近 1 的点估计直接当作显著提升。

交互分数 I=ln(Ti*Tj/(Tbase*Tij))。当两单独动作都有合法独立控制且通过所有前缀门禁时才计算。正值表示超过两单项乘性基准，组合是否最快另查实测排名。两序终态一致只计一次。最佳双步改进用本区域已测两动作计划的最小延迟作为分子。

registers、shared、spill 来自编译元数据；理论 occupancy 来自 CUDA driver occupancy API。CTA 数按 grid 得到。估计字节说明逻辑对象与写入范围，不能等同设备实际 DRAM 流量。任务插桩的 GPU 全局时钟测得开始、结束和 worker，通过前驱计算 critical path、跨 worker 边和 ready gap。插桩路径与计时路径分开运行。缺失计数器保留 UNAVAILABLE。成本列含来源标签。
