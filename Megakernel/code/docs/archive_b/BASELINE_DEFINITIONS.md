# 同轮对照

B0 是 Stage A 的 PyTorch 未融合执行。B1 是同一 Stage B Megakernel 的无策略执行，包含必要状态复位。B2 是输入语义相同、历史验证合格的 Stage A 单策略在本轮逐个重编译、复测后的最快值。其原始单策略及配对基线走随包原样保留的 Stage A 源码。B3 是实际编译并验证的联合计划。Stage B 自身的单动作实测也单列，可区分参数搜索收益与新的变换收益。

功能分组包含工作负载、shape、dtype、算子及数值语义。tile、workers 等可调参数不构成不同数学输入。每个区域、比较方案共用一次输入种子，按同一采样协议运行。历史时间只用于选地区与记录对照背景。完整 12 批，每批 3 次；Smoke 10 批、每批 2 次。GPU 事件计时，支持时图回放，每批交错模式顺序。附带有限/缺失合格单策略个数。两步实验表的 C0 到 C4 是该行局部对照编号，分别指无策略、第一项、第二项、正序和逆序。
