# 合法性与数值门禁

S1 要求消费者需求在同一 Program 的局部像空间、有效掩码和数据版本内，使用 GF(2) 消元得到坐标见证。W7 的两条投影边分别检查并保留低精度投影边界。S2 要求合并块的带掩码并集覆盖原域，普通输出写入唯一。W8 使用逻辑坐标 (batch, head, query*key_length+key)，最后一轴全在任务内；头 13 映射到合法尾组，KV 头仍按 head//7 计算。

S3 要求 RMS、LayerNorm 或 Softmax 的统计量在消费前就绪，原始输入仍存活，并在原有低精度边界舍入。S4 的有序半开区间必须相接、互斥、含尾片，消费端以 32 元素计划单元累加。只有一片或已有相同面板视为 NO_OP。S5 要求拓扑有序且执行依赖包含所有数据前驱，采用 GPU scope release/acquire 发布和原子 claim。每次扫描有界，Worker 可退出，发布者仍能推进就绪任务。运行时校验完成次数和插桩的先后关系。

静态合法后才能编译。编译得到的 shared memory、运行资源限制及实际编译错误单列。所有前缀通过独立 PyTorch 参考、重复运行、正常/极值输入检查，W1 另测 stride，W8 核对 KV 内容并预先确定本环境各投影的偏置舍入。任何失败均使该次候选失去性能样本。数值契约用各工作负载和 dtype 对应的 Stage A 容差。有限测试不能构成任意输入的浮点等价证明。
