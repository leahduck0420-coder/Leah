# 定位失败与恢复

- Stage A 来源不匹配时先打开导入审计，核对原始 manifest、schema、每例记录和代码指纹。选择单次未过滤 Full，保留历史失败行。
- 输出目录已有不同协议时，新建输出目录或恢复原命令的参数和环境。输入、代码、环境或资产变化会改变签名。不要手改记录获得通过。
- 设备已被另一次本工程占用时，等前一任务退出。非法设备访问或超时会隔离当前运行；解决原因后原命令 --resume，候选逐条核对实际产物后才复用。检查 10_logs/error.log 和每例 traceback。
- 资源超限检查编译元数据、形状和单候选显存预算。编译成功但 CUBIN 或前缀物理证据不全时在报告中标记 BLOCKED。无同工作负载位置的组合查 compatibility_matrix.csv 和 target_coverage.csv。
- 图表缺点时检查 qualified 与失败门禁；无测量时图中解释缺失，不画模拟点。GUI 无须安装；使用 Matplotlib Agg。
- 仅约束某一工作负载或较小预算时保留这次结果独立归档。Smoke/过滤数据的验收表会注明覆盖范围。
